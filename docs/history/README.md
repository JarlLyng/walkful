# Historical specs

Two planning documents from before Walkful launched, written in Danish in June 2026
and kept for context.

- **[PRD.md](PRD.md)** — the original product document: vision, scope, the MVP cut.
- **[TECH_PLAN.md](TECH_PLAN.md)** — the original technical plan: stack, structure, milestones.

**They describe what was planned, not what shipped.** The app was at 1.1.x by September
2026, with a paywall that has shipped and been fixed since, and parts of the technical
plan, the data models in particular, were never built as written.

For the app as it exists:

- [ARCHITECTURE.md](../../ARCHITECTURE.md) for how the code is organised
- [README.md](../../README.md) for what the app does
- [CHANGELOG.md](../../CHANGELOG.md) for how it got there

Audience, positioning and pricing reasoning live in the private
[iamjarl-strategy](https://github.com/JarlLyng/iamjarl-strategy) hub. The versions in
`PRD.md` predate that split and are superseded by it.
